# 数据溯源规范

适用于行情、财务、公告、新闻、宏观、资金、板块及研究结论中的结构化数据。

## 每份数据必须记录

- **来源**：发布机构/网站、直接页面或 API URL；使用第三方中转时同时记录它和原始来源。
- **取数时间**：抓取时刻及所用时区。
- **数据时间**：对应的交易日、财报期、公告时间或统计区间；不得用抓取日期替代。
- **范围**：市场、交易所、证券/板块、字段、筛选条件、分页范围和覆盖缺口。
- **定义和单位**：币种、股/手/份、元/万元/亿元、百分数/小数、成交额口径、复权口径等。
- **转换**：清洗、单位换算、复权、聚合、排序、过滤、公式及参数；关键计算须能复算。
- **完整性和限制**：缺失、延迟、缓存、停牌、非交易日、接口分页、仅当前快照、估算/推演等限制。

建议表头：

| 字段 | 值 | 来源 URL | 数据时间 | 抓取时间/时区 | 单位与口径 | 转换/公式 | 完整性与限制 |
|---|---|---|---|---|---|---|---|

## 核验原则

1. 对规则、市场数据、公司公告及可能变化的信息，优先读取官方原始来源；需要实时状态时重新查证。
2. 供应商文档可以解释接口契约，但不能单独证明某次返回真实、完整或当前有效。
3. 对证券代码、市场前缀、财报期间、除复权、币种、成交量和百分数进行合理性核对；避免因错路由静默得到另一只证券的数据。
4. 关键指标至少做一次独立复算或独立来源比对。无法交叉核验时写明原因、范围和剩余不确定性。
5. 明确区分“来源未披露”“查询为空”“接口失败”和“解析失败”。
6. 资金流、筹码推演、预测、媒体观点与模型推断不得描述成已观察到的客观事实。
7. 对新闻记录事件发生时间、消息发布时间、预计影响日期和原始出处；同一事件转载合并。
8. 不确定、来源冲突、时间过旧或数据不完整的字段须标记为待核验/缺失，不能为了完整表格而填猜测值。

## 审查输出

每个核心结论须能从结论追溯到计算/文本，再追溯到来源记录。审查者应抽查来源是否支持对应字段，而非仅检查 URL 是否存在。把时间戳、字段名、代码、单位和公式纳入可复核材料；敏感凭据、个人身份信息不得随数据提交。
